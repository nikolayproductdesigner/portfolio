# Портфолио Николая Грачева — статический сайт

## Стек и правила
- Чистый HTML/CSS, без сборщиков и фреймворков. JS только точечно (`js/switch.js` — анимация segment control написана Колей, логику пилюли не трогать; работает для каждого `.switch` на странице и шлёт событие `switch:change`: табы на главной, «было / стало» в case-1 — `.switch--toggle`).
- Макет: Figma `C5PJ6TN7vXcKdNRWoVnp3D` («Portfolio — autumn 2026»), страница `site` (node 87:2).
  Фреймы: `main` 734:17796, `ui` 253:11186, `case-1` 734:17860, `case-2` 734:22083, `case-3` 734:22653, `ui kit` 758:6881.
- Цель — один в один с Figma на 1440. Адаптив без макетов (решения согласованы с Колей):
  десктоп ≥1024 — лейаут из Figma, тянется на всю ширину без ограничения; планшет 768–1023 — карточки главной в колонку (текст → обложка), шрифты на шаг меньше; мобилка ≤767 — отступы 16, в шапке главной без cv/tg (они в футере), в шапке кейсов cv/tg остаются.
  «Собранные» блоки (ряды телефонов, «Новый дизайн», до/после, шоты ui) не перестраиваются, а уменьшаются целиком: `data-fit="<ширина в макете>"` + `js/fit.js` (CSS zoom, коэффициент в `--fit`). Свич «было / стало» компенсирует zoom и остаётся в натуральную величину.
  Колонки кейсов — `min(1158px, …)` / `min(692px, 100%)`, ховеры — только `@media (hover: hover)`.
- Хостинг: GitHub Pages (позже свой домен). Папки `_old/` и `_sources/` в репозиторий не добавлять.
- Шрифты — триалы TT Interphases Pro (некоммерческий проект), woff2 в `fonts/`.

## Структура
- `css/tokens.css` — цвета, тени, отступы из Figma (в Figma нет Variables, значения сняты с макета).
- `css/base.css` — @font-face, ресет, типографика. `css/components.css` — кнопки (small 40 / middle 52 / big 100 / dark), switch (+ `.switch--toggle`), шапка.
- `css/home.css` — главная (табы «кейсы» и «ui сахар»). `css/case.css` — страницы кейсов.
- Обводки Figma: Stroke Inside 0.5px → `box-shadow: inset 0 0 0 0.5px` (`--stroke-inside`); Stroke Outside у скриншотов → `box-shadow: 0 0 0 Npx`.
- Списки «Аргументы» в кейсах: номера висят за левым краем колонки 692px (`padding-left: 0`) — так совпадает с Figma.
- Типографика: предлоги, союзы и частицы до 3 букв (в, и, к, на, над, для, где…) привязаны к следующему слову через `&nbsp;`, числа — к слову («6+&nbsp;лет»), «→» и «×» — к предыдущему слову. Сделано на главной и в заголовках/лидах кейсов (h1–h3, `.case-lead`); обычный текст кейсов — ещё нет.
- Картинки: WebP, 2x от размера в макете, quality 95. Исходники PNG — в `_sources/`.
